# 东方古典手卷美学与原型交互规范 (Prototype Specification)

## 1. 原型美学灵魂（郭熙气象 · 倪瓒逸韵）

本原型彻底摒弃了现代 Web 前端生硬的“白底圆角卡片盒子（Container Box）”，以北宋 **郭熙《林泉高致》之气象** 与元代 **倪瓒之极简逸韵** 为灵魂，重构为一幅**澄心堂熟宣水墨手卷**：

### 东方空间与笔墨体系：
* **郭熙“三远法”与多维认知**：
  * **平远（江天辽阔）**：横向铺展的自右向左竖排正文墨迹长卷；
  * **深远（重叠幽邃）**：熙宁党争、乌台诗案的时代漩涡与历史考据；
  * **高远（超脱巍峨）**：水月之辩中的哲学突围与精神和解。
* **倪瓒“去容器化”与纯粹留白**：
  * 彻底拆除一切现代 UI 边框与浮夸阴影，文字直接落墨于宣纸原生纤维；
  * 墨分五色（焦、浓、重、淡、清），依靠疏朗行气与烟云变灭界定信息层级。
* **宋代尺牍手札交互**：
  * 点击字句朱印，如轻展一幅**宋代蝉翼素笺折页**，按需调阅深层心鉴、潜台词与东坡对谈。

### 展卷与视口初始化规范：
1. **视口默认停靠在物理最右侧（【卷首】）**：
   - 页面加载完毕即自动定位到卷首大字题签，读者第一眼看到的是从右侧开启的篇名与第一段。
2. **滚轮顺应展卷认知**：
   - 鼠标滚轮向下滚（通常表示“阅读推进”），视口自动**向左平滑展开手卷**（推进至第二段、第三段……直至卷尾）；
   - 鼠标滚轮向上滚，视口自动**向右回卷**（回到卷首）。
3. **按钮与导引一致**：
   - `卷首 (起) ▶`：瞬间平滑回到最右侧卷首；
   - `向左展卷 ➔`：逐步向左移动；
   - `◀ 卷尾 (款)`：平滑移动到最左侧东坡落款处。
