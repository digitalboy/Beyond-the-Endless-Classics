## 📌 二、 详细功能分级规范

### 1. Must Have（核心基石 · MVP 必须交付）

| 功能编号 | 模块分类 | 功能名称 | 详细说明与验收标准 |
| :--- | :--- | :--- | :--- |
| **M-00** | **首页剧场** | **先贤星汉群像与交互式水墨短剧引擎** | • 首页呈现历代先贤白描群像，突破按篇目死板分类；<br>• 点击作者头像触发电影级水墨烟云渐变、命运天命轴推进与篇章手札破墨渐次浮现；<br>• 形成“选人 ➔ 历经命途转折 ➔ 篇章手札浮现 ➔ 运镜入卷”的四幕式交互短剧体验。 |
| **M-01** | **古典排版** | **澄心堂水墨竖排手卷引擎** | • 自右向左纯正古典竖排排版（`writing-mode: vertical-rl`）；<br>• 滚轮横向丝滑展卷、支持拖拽展卷与首尾瞬时导航；<br>• 纯正宣纸底色，彻底去容器化（Borderless 无生硬卡片）；<br>• 移动端与不同分辨率下文字不重叠、不断行错位。 |
| **M-02** | **文本知识** | **结构化全要素知识体系** | • **版本校勘**：底本与异文标注，生僻字注音与通假字释义；<br>• **白话精译**：逐段信达雅现代翻译与工笔小题；<br>• **文字潜台词（Subtext）**：剖析下笔一刻深层心理与隐秘动机；<br>• **典故溯源（Allusions）**：原典出处、原文金句与政治哲学寄托；<br>• **名家评点（Commentaries）**：收录清代吴楚材《古文观止》原评及明清名家朱批/总评。 |
| **M-03** | **视觉资产** | **传世名品与多模态资产** | • **先贤画像 (PORTRAIT)**：传世名画绣像（如赵孟頫绘东坡像）；<br>• **传世名画 (MASTERPIECE)**：同题历史名画（武元直《赤壁图》等）；<br>• **书法墨宝 (MANUSCRIPT)**：作者手泽书法真迹或碑刻拓本；<br>• **工笔情境 (SCENE)**：郭熙平远山水意境原画；<br>• 统一保存在 Cloudflare R2（零出站流量费）。 |
| **M-04** | **时空地理** | **古今时空地理沙盘** | • 古今地名精准对照（古地名 ➔ 现今行政区划与遗址公园）；<br>• WGS84 经纬度映射与现场微环境描述（江心溯流、军营驻地）；<br>• 标准 ISO 8601 时间与古代朝代帝王干支纪年双轨呈现。 |
| **M-05** | **时代局势** | **时代风云与政治局势折页** | • 详述文章诞生时朝廷的政见对立、朋党倾轧与皇权意志；<br>• 剖析政治事件对作者身心造成的不可逆挤压。 |
| **M-06** | **数据底层** | **Cloudflare D1 边缘数据库** | • 采用“静态典籍语义 Slug，动态交互 UUIDv7”的分层 ID 策略；<br>• 提供秒级响应的 Edge 只读查询，Schema 覆盖作者、篇目、段落、典故、人物、评点与资产。 |
| **M-07** | **用户认证** | **Firebase Google 账号体系** | • 基于 Firebase Auth 提供 Google OAuth 2.0 一键快捷登录；<br>• 边缘端 JWT 验签鉴权，打通用户个人收藏、先贤对话记录与朱砂批注的跨端同步。 |
| **M-08** | **多语言体系** | **简繁双体实时切换 (zh-Hans / zh-Hant)** | • 界面 UI 与古典长卷支持 **简体中文** 与 **正体/繁体中文** 丝滑一键切换；<br>• 采用专业级词库转换（精细处理“後/后”、“發/髮”等古典异体通假），保持古典书法与竖排长卷原汁原味的古雅气韵；<br>• 支持 URL 语义化国际化路由（如 `/zh-hans/...` 与 `/zh-hant/...`），兼顾全局 SEO。 |
| **M-09** | **SEO 与收录** | **动态 SEO、Sitemap 与结构化数据** | • **动态 Sitemap**：根据 D1 篇目与作者自动生成 `sitemap.xml` 与 `robots.txt`；<br>• **简繁双轨 Hreflang**：自动注入 `alternate hreflang` 与 `canonical`；<br>• **Schema.org JSON-LD**：注入 Article、Person、Breadcrumb 富媒体数据；<br>• **水墨动态 OG Image**：Edge 动态渲染宣纸朱印社交分享卡片。 |

### 2. Should Have（重要特性 · 完整体验不可或缺）

| 功能编号 | 模块分类 | 功能名称 | 详细说明与验收标准 |
| :--- | :--- | :--- | :--- |
| **S-01** | **先贤对话** | **先贤数字分身 (Persona Agent)** | • 严格基于《宋史/三国志/唐书》、人物年谱、文集限定的 System Prompt；<br>• 绝不胡编乱造，以第一人称口吻与特定历史阶段的心境回答读者关于人生困惑的提问；<br>• 内置每篇经典的灵魂快捷问签（如“被贬黄州如何不内耗？”）。 |
| **S-02** | **古今映射** | **当代心镜共鸣引擎** | • 将千年前古人的处境（职场贬谪、天下危局、至亲离散）与当代青年痛点（35岁危机、职业内耗、亲情焦虑）建立映射卡片；<br>• 提炼先贤在绝境中的哲学破局智慧。 |
| **S-03** | **检索系统** | **FTS5 典籍全文极速检索** | • 借助 SQLite FTS5 引擎，支持对 222 篇古文原文、字词注、生僻字、典故与名家评语进行毫秒级全文模糊检索；<br>• 支持按朝代（周/秦/汉/唐/宋/明）、文体（赋/表/祭文/记/论）快速筛选。 |
| **S-04** | **装帧自适应** | **文体特征自适应装帧** | • 根据篇目文体（`genre`）自动匹配最地道的古典装帧风格：<br>  - 文赋类：水墨长卷，平远舒朗；<br>  - 表疏类：奏折折本，朱印庄严；<br>  - 祭悼类：素笺哀册，清冷悲切。 |
